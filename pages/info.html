Comment fonctionnent les algorithmes ?

César

Le chiffrement de César est une méthode de substitution simple qui consiste à décaler chaque lettre du message d’un certain nombre de positions dans l’alphabet, déterminé par une clé. Par exemple, avec une clé de 3, la lettre "A" devient "D", "B" devient "E", et ainsi de suite. Ce décalage est circulaire, ce qui signifie que "Z" revient à "C". Bien que facile à comprendre, ce chiffrement est vulnérable aux attaques par force brute.

  • Type : Substitution par décalage
  • Avantages : Simple à implémenter
  • Inconvénients : Peu sécurisé face aux attaques modernes

Vigenère

Le chiffrement de Vigenère est une amélioration du chiffrement de César. Il utilise une clé composée de lettres pour appliquer des décalages différents à chaque lettre du message. La clé est répétée ou tronquée pour correspondre à la longueur du texte. Par exemple, avec le message "BONJOUR" et la clé "CLE", chaque lettre du message est décalée en fonction de la lettre correspondante de la clé. Cette technique rend le chiffrement plus complexe et résistant aux attaques par fréquence.

  • Type : Substitution polyalphabétique
  • Avantages : Plus sûr que César
  • Inconvénients : La clé doit rester secrète et être mémorisée

XOR

Le chiffrement XOR (OU exclusif) est basé sur une opération logique binaire. Chaque caractère du message est combiné avec un caractère de la clé en appliquant l’opération XOR (⊕) au niveau de leurs représentations binaires. Ce chiffrement est réversible : appliquer XOR une seconde fois avec la même clé redonne le texte original. Pour être sûr, la clé doit être au moins aussi longue que le message et aléatoire (comme dans le "one-time pad").

  • Type : Chiffrement binaire
  • Avantages : Très sûr avec une clé aléatoire unique
  • Inconvénients : La clé doit être aussi longue que le message pour une sécurité optimale

Exemple de chiffrement XOR :

Message : A
Clé : K

Chaque caractère est converti en son code binaire ASCII :

  • A = 65 (binaire : 01000001)
  • K = 75 (binaire : 01001011)

Ensuite, appliquez l'opération XOR entre les deux :

               01000001 (A)
            ⊕ 01001011 (K)
            -----------------
               00001010 (résultat en binaire)

Le résultat binaire (00001010) correspond au caractère ASCII : 10 (␊(line feed), saut de ligne).

Déchiffrement :

Appliquez XOR à nouveau avec la clé (K) :

               00001010 (résultat précédent)
            ⊕ 01001011 (K)
            -----------------
               01000001 (A, le message d'origine)

Le processus est réversible, et le message d'origine "A" est récupéré.
